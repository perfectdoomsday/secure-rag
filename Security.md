
# Security Policy

## Supported Versions

Security updates are provided for the latest version
of Secure RAG on the main branch.

## Reporting a Vulnerability

If you discover a security vulnerability:

1. Do not disclose it publicly.
2. Do not publish API keys, credentials, or private documents.
3. Report the issue privately to the project maintainer.
4. Include reproduction steps and potential impact.

## Security Practices

This project follows these security practices:

- Environment variables for sensitive configuration.
- No API keys committed to source control.
- Input validation and sanitization.
- Authentication and authorization controls.
- Protection against prompt injection.
- Secure document ingestion.
- Restricted file uploads.
- Logging and monitoring.
- Dependency vulnerability checks.

## Responsible Disclosure

Please allow the maintainer reasonable time to
investigate and resolve reported vulnerabilities
before publicly disclosing them.
